# CAST-ADMET-Consensus-Anabolic-Steroid-Targeting-ADMET
In silico prioritization framework for anabolic-androgenic steroids (AAS) in anti-doping control. Combines multi-algorithm consensus target fishing, predicted metabolite validation (BioTransformer 3.0), and ADMET profiling (ADMETlab 3.0, pkCSM, admetSAR 3.0) to proactively identify designer steroids.
